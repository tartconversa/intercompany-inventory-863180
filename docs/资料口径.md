# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

legal_trade表示所有权变化，physical_moves表示库位变化，二者互不替代。交易quantity为kg、amount为原交易币种正金额；return_of指向原交易且只撤回仍可追溯的对应份额，不自动冲销已经外售的份额。双边link给明确对照，不能按净额猜；匹配容差数量0.01kg、原币0.01元，截止差异两边date跨月但link相符。每项内部交易明确original_currency，双方用其核对，local_amount与本位币转换差额单列。库存出库采用资料明确的flow_allocations对应份额；mix_inputs均匀混合，每次出库按各来源剩余量比例携带价值，不可选高低成本顺序。无法定位的出库保留unresolved，不强行消耗任意来源。集团列报CNY，单体A为CNY、B为USD、C为CNY。内部加价仅在外部销售对应份额释放，集团内再次销售增加价值层但不重复释放。期末内部收入成本、往来与存货加价三个口径分别核对。

## fx

记录键：['currency', 'date']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| currency | string | 币种 |
| date | date | 日 |
| cny_per_unit | number | 人民币每单位 |

同一来源记录键的新文件表示整行修订，调用者明确接收次序；原始文件和接收历史须保留。相同文件摘要不增加事实。下面标为后续接收的文件不随基础资料自动生效，用户可分次装载。历史事实的业务时点与本次接收时点分开。金额除另述外人民币元，结算舍入到分的尾差归该账单分摊基数最大项，并列按业务键升序。本文规定来源语义，不规定待开发仓表、算法或架构。

内部退货超出原交易链未外售余量的部分保留争议，不撤销原外售。集团存货成本用取得时点汇率，往来月末用月末汇率，汇兑差不并入经营加价。管理包期间为自然月。

原始采购T0是集团取得成本。P0中未内部售出的20kg仍属A，P1中未售C的30kg仍属B，mix投入将P2与P3变为PM，不在原池重复保留量。T4外售时按混池比例带出两来源；later_returns从P1未再售的部分退回。双方单据local_amount为真实声明值，与按每日fx重算不同要解释为币种差异或待核，不能覆盖原值。
